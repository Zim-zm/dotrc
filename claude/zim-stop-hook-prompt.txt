Run this command first: hooks/commit/zim-review-gate.sh <cwd> <stop_hook_active>, where <cwd> and <stop_hook_active> are the values of those two fields in the hook input JSON below, and the command runs from the worktree root that <cwd> names. If its first line starts with SKIP, answer {"ok": true} and stop. Otherwise the command prints the procedure, the rules, the commits with their mechanical verdicts, and the path of a diff file: follow that procedure, read that diff file to its end, and answer as it says, with one translation. When the procedure's answer is {"ok": true, "notes": ...}, the pass is recorded, and this hook can show text to the user only through a refusal: answer {"ok": false, "reason": "The style review recorded a pass. These notes block nothing: report them to the user as they are, and fix nothing unless the user asks. <the notes>"}. Hook input JSON: $ARGUMENTS
